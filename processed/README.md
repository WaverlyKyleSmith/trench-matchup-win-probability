# processed/

This folder holds intermediate data files generated by the notebooks. They are **not included in this repository**: they are row-level data derived from the NFL Big Data Bowl 2023 competition data, which cannot be redistributed under the competition's data terms.

Running the notebooks in order regenerates them:
| File | Created by |
|---|---|
| `snapshot_features.parquet` | `02_snapshot-features.ipynb` |
| `xgboost_predictions.parquet` | `03_xgboost.ipynb` |
| `lstm_predictions.parquet` | `04_lstm.ipynb` |
| `model_comparison.parquet` | `05_model-comparison.ipynb` |
| `full_preds.parquet` | `06_dashboard-export.ipynb` |

See the root README for how to obtain the raw data these notebooks require.
