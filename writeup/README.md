# writeup/

| File | Contents |
|---|---|
| `writeup.qmd` | Quarto source for the technical writeup |
| `writeup.pdf` | The rendered PDF |

To re-render, install [Quarto](https://quarto.org) and a LaTeX distribution, then run:

```
quarto render writeup.qmd
```

The document pulls figures from `../figures/`, so keep the folder layout as it is.
